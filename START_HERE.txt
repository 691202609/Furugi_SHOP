FURUGI SHOP v4.1 — GO LIVE FINAL

ทำตามนี้ตามลำดับ:
1) Supabase Database
   - ถ้าใช้ฐานข้อมูลเดิม: เปิด RUN_THIS_IN_SUPABASE.sql > Copy ทั้งหมด > Supabase SQL Editor > Run
   - ถ้าเป็น Supabase ใหม่: Run supabase/READY_TO_OPEN.sql แทน

2) Supabase Authentication > Sign In / Providers > Email
   - ปิด Allow new users to sign up (สำคัญ: ป้องกันการสมัครตรงข้าม Backend/Rate Limit)
   - ระบบ Furugi สมัครผ่าน /api/customer/register ด้วย Server Admin API และสร้างบัญชี confirmed ให้เอง
   - ลูกค้าจึงสมัคร/Login บนหน้าเว็บได้ทันที ไม่ต้องยืนยัน Gmail

3) Vercel > Settings > Environment Variables ต้องมี
   SUPABASE_URL
   SUPABASE_PUBLISHABLE_KEY
   SUPABASE_SECRET_KEY
   FURUGI_SETUP_TOKEN  (ใช้เฉพาะสร้าง Admin คนแรก; สุ่มยาวอย่างน้อย 32 ตัว)

4) Push ชุดนี้ขึ้น GitHub main แล้วรอ Vercel Deploy

5) เปิด https://furugishop.vercel.app/api/health
   ต้องได้ "ok": true และ checks ทุกตัวเป็น true

6) เปิด /setup.html สร้าง Admin คนแรก
   จากนั้นลบ FURUGI_SETUP_TOKEN ออกจาก Vercel แล้ว Redeploy

7) Logout/Login ใหม่ 1 รอบหลังอัปเดต เพราะ Customer/Admin ใช้ Auth storage key ใหม่แยกกัน

8) Smoke Test ก่อนประกาศเปิดร้าน
   Register > Login > Profile > Shop > Product > Cart > Checkout > Order > Track
   Admin > Products > Orders > Payments > Customers > Settings > Backup

สำคัญ:
- Register/Login ไม่ต้องยืนยัน Gmail
- Forgot Password ยังใช้อีเมล Recovery: ก่อนเปิดจริงควรตั้ง Custom SMTP ใน Supabase
- ห้ามอัป .env.local หรือ Secret/Setup Token จริงขึ้น GitHub
- หลังสร้าง Admin แล้วต้องลบ FURUGI_SETUP_TOKEN
